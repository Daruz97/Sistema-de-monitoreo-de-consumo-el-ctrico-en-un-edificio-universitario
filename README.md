# Sistema de Monitoreo de Consumo Eléctrico

Repositorio del proyecto de tesis de maestría, enfocado en el monitoreo del consumo eléctrico en edificios universitarios, basado en la integración de dispositivos de Internet de las Cosas (IoT) y herramientas de inteligencia artificial para la recopilación y el análisis de datos de consumo energético eléctrico en áreas operativas de trabajo, con el fin de identificar patrones de consumo y proporcionar información para la toma de decisiones sobre el consumo eléctrico.


## Características Principales

* **Monitoreo IoT:** integración de sensores para la captura de datos de consumo energético eléctrico.
* **Análisis de Datos:** procesamiento y entrenamiento para predecir consumos y detectar anomalías.


## Estructura del Repositorio

* `/data` - Conjunto Reportes por sensor.
* `/src` - Código fuente del sistema de monitoreo y análisis.
* `/models` - Algoritmos y modelos entrenados para predicción de consumo.
